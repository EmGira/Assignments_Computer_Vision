# Assignment 1: Image Enhancement

## Project structure

```
Assignment1/
├── image_enhancement.ipynb   # all the code
├── Analysis.md               # metrics, visual comparisons and discussion
├── images/                   # original images (see sources.txt)
└── results/                  # images generated by the notebook
```


## Setup

From the root of the repository:

```bash
python3 -m venv venv
source venv/bin/activate        # on Windows: venv\Scripts\activate
pip install -r requirements.txt
```

## Run

```bash
cd Assignment1
python image_enhancement.py
```

Or open `image_enhancement.ipynb` in VS Code and select the `venv` kernel.
